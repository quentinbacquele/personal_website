# Quentin Bacquelé — Personal Website

Personal research website of Quentin Bacquelé, a PhD candidate studying the global diversity and evolution of bird vocalizations through bioacoustics, artificial intelligence, and biogeography.

[Visit the website](https://quentinbacquele.vercel.app/)

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
